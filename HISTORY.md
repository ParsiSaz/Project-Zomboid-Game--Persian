# Changelog & Version History

All notable changes to the **Project Zomboid Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Standardized repository architecture to conform with the **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Organized 25+ language definition files into decoupled `loc/fa-IR/` and game drop-in `game_assets/media/lua/shared/Translate/FA/`.
- Published comprehensive signature `README.md` with installation guides and troubleshooting.

---

## [v1.1.0] - 2023-11-20

### Added
- Completed survival guide, crafting recipes, and dynamic emergency broadcast radio scripts.
- Configured font glyph adjustments for Build 41 multiplayer.

---

## [v1.0.0] - 2022-09-10

### Initial Release
- Initial Persian language mod for Project Zomboid (UI, items, moodles, and menus).
